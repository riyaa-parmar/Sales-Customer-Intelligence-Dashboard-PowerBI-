# 📊 SalesSight BI – Enterprise Sales & Customer Intelligence Dashboard

## 📌 Project Overview

SalesSight BI is an interactive Power BI dashboard developed to analyze sales performance, customer behavior, product insights, and regional distribution. The project enables business users to monitor KPIs, identify trends, evaluate product performance, and make data-driven decisions through interactive visualizations.

---

## 🎯 Objectives

- Monitor overall business performance.
- Analyze customer purchasing behavior.
- Evaluate product sales and profitability.
- Compare regional performance.
- Provide detailed product-level insights through Drillthrough.
- Enhance user experience using Custom Tooltips and interactive navigation.

---
